# 手机 APP 使用手册

## 1. 首页

首页提供华侨生判定、国际生判定、国籍法条款、大学库、招生时间、智能AI助手和历史记录入口。底部导航可快速切换大学、时间、智能AI助手和历史模块。

## 2. 一步一屏判定

点击“华侨生判定”或“国际生判定”后，APP 会进入四步流程：

1. 身份信息：姓名、出生日期、当前国籍、中国/外国国籍状态。
2. 居住与家庭：海外定居、户籍、出生地、父母国籍与居住状态、海外居住月份。
3. 推荐条件：意向专业领域和分数/成绩。
4. 确认提交：调用后端判定并保存记录。

## 3. 结果页

结果页展示：

- 合格 / 不合格标识
- 详细判定理由
- 对应《中华人民共和国国籍法》条款原文与解释
- 根据资格类型、专业领域、成绩推荐的大学
- 每所推荐大学的排名、标签、领域、优势专业、招生时间和报考链接

点击“保存结果到相册”会生成结果图片。手机浏览器中通常会保存到下载，用户可从下载或分享菜单保存到相册。

## 4. 大学库

大学库支持按华侨生/国际生、专业领域筛选。数据直接来自后端 SQLite，包含前 50 高校和体育、音乐、美术、设计特色高校。

## 5. 招生时间轴

招生时间轴按月份纵向展示报名、材料截止、考试/审核时间和关键提醒。

## 6. 智能AI助手

输入个人背景和政策问题，APP 会调用现有后端智能AI助手接口。后端配置 AI_API_KEY 后使用智能AI助手；未配置时使用本地规则助手兜底。

## 7. 历史记录

历史记录展示所有已保存判定，支持下拉刷新。记录存储在后端 SQLite 中，与 PC 端共用。

## 8. 手势与主题

- 屏幕左边缘右滑可返回上一页或上一步。
- 右上角开关可切换深色/浅色模式，设置会保存在本机浏览器或 APP WebView 中。
