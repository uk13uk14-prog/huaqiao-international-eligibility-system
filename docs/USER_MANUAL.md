# 使用手册

## 1. 华侨生资格判定

进入“华侨生判定”页，填写姓名、出生日期、当前国籍、海外定居状态、近两年海外居住月份、户籍状态等信息。点击“开始判定”后，系统会独立调用华侨生规则，不会读取国际生模块状态。

结果页会展示：

- 合格 / 不合格标识
- 详细判定理由
- 《中华人民共和国国籍法》对应条款原文
- 条款解释与补充建议
- 复制、打印按钮

## 2. 国际生资格判定

进入“国际生判定”页，填写外国国籍、中国国籍状态、取得外国国籍日期、出生地、父母国籍/定居情况、近四年海外居住月份等信息。点击“开始判定”后，系统会独立调用国际生规则。

国际生模块重点关联国籍法第 3、5、9、14 条，用于解释双重国籍、海外出生、定居外国并取得外国国籍、国籍申请手续等问题。

## 3. 国籍法条款查看

进入“国籍法条款”页可查看系统内置的国籍法全文条款。输入关键词后，条款内容会自动筛选并高亮，便于对照判定结果。

## 4. 大学信息查询

进入“大学库”页，按“华侨生”或“国际生”筛选高校。每所学校提供简介、报考要求摘要和官方招生链接。

## 5. 招生时间管理

进入“招生时间”页，按招生对象和月份筛选报名时间、材料截止时间、考试/审核时间。提醒字段用于标记关键节点。

## 6. 智能AI助手咨询

进入“智能AI助手”页，输入身份背景和问题。配置 AI_API_KEY 后，系统会调用智能AI助手结合国籍法全文进行解释；未配置时会使用本地兜底回答。

## 7. 历史记录

每次判定都会写入 SQLite。进入“历史记录”页可查看最近 200 条记录，数据保存在 `backend/eligibility.db`。

## 8. API 文档

后端启动后访问 `http://127.0.0.1:8000/docs`，可在线调试全部接口。

## 9. 大学推荐

在华侨生或国际生判定表单中选择“意向专业领域”，可选填写分数/成绩。系统会根据资格类型、专业领域、成绩区间、大学排名、C9/985/211/双一流标签和特色专业自动推荐大学。

推荐结果直接展示在判定结果页下方，字段包括：

- 学校名称与排名
- 标签
- 专业领域
- 优势专业
- 招生时间轴
- 推荐理由
- 报考链接

## 10. 升级后的大学库

大学库已补充中国大学排名前 50 名，并包含体育、音乐、美术、设计类特色顶尖高校。系统启动时自动写入 SQLite，并兼容旧数据库自动补列。
